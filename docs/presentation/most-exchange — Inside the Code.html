One schema, every process
Codecs are generated at build time. Nobody writes a byte offset by hand.
Versioned, not replaced
New fields are appended: cumQty in version 3, reportSeq in 6. An older message still decodes.

03 · The order book
Two flat structures, no objects
object OrderField {     const val STRIDE = 8 // 64 bytes     const val PRICE = 0     const val LEAVES_QTY = 1     const val PARTICIPANT_ID = 2     const val SMP_ID = 3     const val CL_ORD_ID = 4     const val EXCHANGE_ORDER_ID = 5     const val LINKS = 6 // next|prev     const val META = 7 }
One LongArray, eight longs per order: one cache line. What matching never reads, like origQty, sits in a parallel cold array.
// Best bid: highest occupied level at or below start var w = from ushr 6 var word = occupancy[w] and (-1L ushr (63 - (from and 63))) while (true) {     if (word != 0L)         return (w shl 6) + (63 - word.countLeadingZeroBits())     if (w == 0) return NULL_LEVEL     w--     word = occupancy[w] }
One bit per price level. A leading-zero count finds the next best price, 64 levels per step.

04 · Matching
Inline, collar first, then self-match
inline fun matchAggressive(…, onFill: (…) -> Unit, …) {     val collarReference = dynamicReference // taken once, on arrival     val bound = dynamicBound(collarReference)     levels@ while (remaining > 0) {         val level = if (takerSide == BUY) bestAskLevel else bestBidLevel         if (breachesDynamicCollar(levelPrice, collarReference, bound)) {             outcome.status = MatchStatus.COLLAR_BREACH; break@levels         }         while (remaining > 0) {             val maker = ladder.head[level] // FIFO: time priority             if (orders[maker * STRIDE + SMP_ID] == takerSmpId) { … }             dynamicReference = levelPrice             onFill(maker, levelPrice, fill, makerAfter)         }     } }
Why inline
The callbacks are pasted into the caller: no lambda, no boxing. Drop the keyword and it still compiles; only the allocation test notices.
Collar per level
Against the reference taken on arrival, not the price the order's own fills move.
Then self-match
Per resting order, before the fill is applied.

05 · Output
Kept on every node, then claimed
// Numbered and retained first, on every node val reportSeq = lastReportSeq.get(participantId) + 1 lastReportSeq.put(participantId, reportSeq) val slot = reportRing.append(participantId, reportSeq) execReportEncoder.wrapAndApplyHeader(reportRing.buffer, …)     .cumQty(cumQty).reportSeq(reportSeq) // stated, never subtracted
val result = session.tryClaim(ReportRing.REPORT_LENGTH, claim) if (result == ClientSession.MOCKED_OFFER) return true // a follower if (result > 0) {     claim.buffer().putBytes(         claim.offset() + AeronCluster.SESSION_HEADER_LENGTH,         reportRing.buffer, reportRing.offset(slot), …)     claim.commit() }
Kept before it is sent
Every node writes the report into its ring, so a resend after a failover can replay it.
Still one claim
The leader copies it into Aeron's buffer with tryClaim. Never offer from a scratch buffer.
Mind the header
Writing at claim.offset() once overwrote the session header. Only the end-to-end run saw it.

06 · The gateway
Reject early, never lose an order
val assembler = ControlledFragmentAssembler { buffer, offset, length, _ ->     when (service.onClientMessage(buffer, offset, length)) {         CONSUME -> Action.COMMIT // never CONTINUE         RETRY -> Action.ABORT // back-pressured: offer it again     } } var work = inbound.controlledPoll(assembler, FRAGMENT_LIMIT)
// First, so a participant it may not act for learns nothing val reason = if (!access.mayPlace(participantId)) UNAUTHORIZED_PARTICIPANT     else validate(securityId, qty, price) return when (sink.toCluster(buffer, offset, length)) {     SENT -> CONSUME     RETRY -> RETRY     FAILED -> { /* reject GATEWAY_UNAVAILABLE */ CONSUME } }
Nothing dropped inbound
An order the cluster cannot take yet stays in the subscription and is offered again.
COMMIT, not CONTINUE
CONTINUE commits at the end of the poll, so a later ABORT would resend orders already forwarded.
Refused before the log
The engine never rejects on a node-local file. The gateway does.

07 · Market data
Feeds drop, they never block
// No back-channel to a multicast group, and blocking would couple // the feed to its slowest reader: a negative offer is a drop. val publisher = SbeFeedPublisher(     shardId = config.shard.shardId,     l3 = FeedSink { b, o, n -> l3.offer(b, o, n) >= 0 },     l2 = FeedSink { b, o, n -> l2.offer(b, o, n) >= 0 },     l1 = FeedSink { b, o, n -> l1.offer(b, o, n) >= 0 },     snapshot = FeedSink { b, o, n -> snapshot.offer(b, o, n) >= 0 }, )
engine.bookEvent.channel=aeron:ipc # stream 12 md.l2.channel=aeron:udp?control=shard0:40002|control-mode=dynamic md.snapshot.channel=aeron:udp?control=shard0:40004|control-mode=dynamic
Engine to feed: IPC
Book events cross shared memory. The engine never formats a feed.
Written once
Whatever the audience. L3 is the engine's event, forwarded byte for byte.
Fastest reader sets the pace
A slow subscriber takes a gap and resynchronises. It slows no one else.

08 · The snapshot feed
One sequence number, read first
// Read before the first level is written: every update after // this point must be replayed on top of the image. val seqNum = publisher.lastDepthSeqNum publisher.publishSnapshotBegin(securityId, l2SeqNum = seqNum, …) book.forEachOccupied(isBid = true) { price, qty, orders -> … } book.forEachOccupied(isBid = false) { price, qty, orders -> … } publisher.publishSnapshotEnd(securityId, seqNum, levels)
// Ignored while synchronised, unless the image is at or ahead // of everything applied: then there is nothing to rewind. if (feed.state == SyncState.SYNCHRONISED &&     l2SeqNum < l2Sequences.lastSeen(shardId)) return feed.state = SyncState.BUILDING
One book per slice
Cycled on the poll thread. A timer thread would publish a torn image no one could detect.
One assembler
The CLI, the console and every adapter use DepthFeedAssembler from client, the SDK.
Recovery sends both
A restored book goes out as increments and a snapshot, because synchronised readers ignore snapshots.
